# Kruxia Foundry

Humans and agents forging software together.

Kruxia Foundry runs software and business work through a staged process: AI agents do the work between checkpoints, and the people who own each decision approve it with evidence in hand. Gates are durable, attributable and resumable, backed by the [Kruxia Flow](https://github.com/kruxia/kruxiaflow) workflow engine. Kruxia Foundry is agent-neutral: it drives existing coding agents through a common driver interface, starting with Claude Code for the proof of concept.

The project is at the design stage. Start with the [product brief](docs/product-brief.md) and the [research report](docs/research/2026-10-03-agentic-coding-harness-prior-art.md).
